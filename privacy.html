Privacy Policy

Last Updated: September 29, 2026 · Effective Date: September 29, 2026
Core Privacy Guarantee: Your data remains strictly on your device. ZentyRecon does NOT collect, transmit, rent, or sell your browsing history, visited URLs, session cookies, or scan findings to external servers.

1. Technical Scope

ZentyRecon is an open-source browser extension engineered for cybersecurity engineers, penetration testers, and developers to analyze Post-Quantum Cryptography (PQC) readiness and perform client-side security audits.

2. Data Processing & Storage

Data Category Purpose Storage Location
Active URL & Origin Detects technologies and crypto cipher suite profile Volatile memory only (RAM)
TLS Handshake Meta Identifies PQC hybrid algorithms (e.g. Kyber768/FIPS 203) Volatile memory only (RAM)
Cookies & Headers Security auditing (Secure, HttpOnly, SameSite flags) Local inspect only
User Preferences Persists UI module tabs, theme, and custom proxy profiles Local browser storage (chrome.storage.local)

3. Chrome Web Store Permissions

  • activeTab / tabs: Scans active tab metadata when user explicitly opens or triggers the extension.
  • sidePanel: Renders the unified 7-module dashboard natively in Chrome's sidebar.
  • storage: Stores local configurations securely on the client machine.
  • cookies: Permits inspection of security attributes on target domains under audit.
  • proxy: Routes browser requests into pen-testing tools (Burp Suite, Tor) at user request.
  • scripting: Injects DOM link and tech detector routines upon page load.
  • webRequest: Inspects TLS handshake protocols for post-quantum crypto classification.

4. Third-Party Disclosures & Advertising

ZentyRecon contains zero tracking pixels, zero analyticsSDKs, zero advertising frameworks, and zero remote data harvesting engines in the Community Edition.
